reverse shell · advanced tips & tricks

what is a reverse shell?

A reverse shell forces the target to initiate a connection back to the attacker's machine, bypassing inbound firewall restrictions. Essential for CTF, HTB, and authorized pentesting.

stabilize your shell 
python3 -c 'import pty;pty.spawn("/bin/bash")'
export TERM=xterm
Ctrl+Z → stty raw -echo; fg → reset
evasion techniques
  • Base64 / URL encoding (select from dropdown)
  • SSL wrapping via openssl or ncat
  • PowerShell with -enc for Windows
common pitfalls
  • Firewall egress filtering — try different ports (443, 80, 53)
  • Missing netcat: use python or bash fallback
  • Windows Defender: obfuscate PowerShell
encoding methods

Plain: raw execution. Base64: echo b64|base64 -d|bash. URL: bypass WAF/URL filters.

listener pro tips
  • rlwrap: adds history and arrow keys to netcat sessions.
  • socat: provides full PTY, tab completion, and signal handling.
  • pwncat-cs: modern listener with file upload/download.
  • Always use stty raw -echo; fg after backgrounding netcat.
